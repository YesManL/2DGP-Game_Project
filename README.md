# Sand Raiders - 2D 탑뷰 액션 서바이벌 게임

## 프로젝트 개요
샌드 레이더는 끝없이 몰려오는 적들로부터 생존하는 2D 탑뷰 슈팅 게임입니다.
웨이브 시스템을 통해 점점 강해지는 적들과 싸우며, 상점에서 무기와 아이템을 구매하여 캐릭터를 강화할 수 있습니다.

## 게임 조작법

### 기본 조작
- **WASD / 방향키**: 플레이어 이동 (차체 회전 포함)
- **마우스 이동**: 포탑 조준
- **마우스 좌클릭**: 무기 발사

### 메뉴 조작
- **마우스**: 모든 메뉴에서 버튼 호버 및 클릭 지원
- **방향키 + Enter**: 키보드로 메뉴 선택
- **ESC**: 상점/옵션 닫기

## 현재 구현된 기능

### 핵심 게임플레이
- ✅ **후륜 차량 물리**: 실제 차량처럼 작동하는 조향 시스템
- ✅ **독립 포탑 조준**: 차체와 포탑이 독립적으로 회전
- ✅ **웨이브 시스템**: 점점 강해지는 적의 웨이브
- ✅ **다양한 적 타입**: 일반 적, RPG 보스 적
- ✅ **적 AI**: 플레이어 추적 및 발사
- ✅ **충돌 시스템**: 플레이어/적/총알 간 충돌 처리
- ✅ **HP 아이템**: 적 처치 시 드롭

### 상점 및 업그레이드
- ✅ **영구 상점 시스템**: 골드로 무기/아이템 구매
- ✅ **3가지 무기**: 기본 총, 샷건, 폭발 총
- ✅ **5가지 아이템**: 체력, 속도, 공격력, 연사력, 체력 회복
- ✅ **웨이브 간 업그레이드**: 4가지 스탯 선택 강화
- ✅ **진행 상황 저장**: 타이틀에서 게임 이어하기
- ✅ **마우스 지원**: 상점 아이템 마우스로 선택 및 구매

### UI/UX
- ✅ **완전 한글화**: 모든 메뉴, UI, 아이템 이름 한글
- ✅ **타이틀 화면**: 애니메이션 로고, 5개 버튼 (게임 시작, 상점, 조작법, 옵션, 종료)
- ✅ **마우스 지원**: 타이틀 및 상점에서 마우스로 선택 및 클릭
- ✅ **조작법 화면**: 게임 조작 방법 상세 설명
- ✅ **옵션 메뉴**: 전체/효과음/배경음 볼륨 조절
- ✅ **HUD**: HP바, 골드, 웨이브, 킬 카운트, 미니맵
- ✅ **게임오버 화면**: 처치 수 표시 및 재시작
- ✅ **커스텀 커서**: 플레이 중 조준 커서

### 시각 효과
- ✅ **폭발 이펙트**: 총알 및 적 사망 시 애니메이션
- ✅ **피격 효과**: 플레이어 피격 시 깜빡임
- ✅ **미니맵**: 실시간 플레이어/적 위치 표시
- ✅ **GUI 애니메이션**: 버튼 맥박, 깜빡임 효과

### 사운드
- ✅ **효과음**: 발사, 폭발, 피격, 적 사망, 아이템 획득
- ✅ **UI 사운드**: 버튼 선택, 구매 효과음
- ✅ **볼륨 조절**: 전체/효과음/배경음 개별 조절 (50% 기본값)

## 게임 플레이 흐름
1. **타이틀 화면**: 게임 시작, 상점, 조작법, 옵션, 종료 선택
2. **상점 (선택)**: 골드로 무기와 아이템 구매
3. **웨이브 전투**: 적을 처치하며 생존
4. **웨이브 완료**: 스탯 업그레이드 선택
5. **반복**: 웨이브마다 강해지는 적과 전투
6. **게임오버**: 처치 수 확인 및 재시작

## 프로젝트 구조
```

├── game_framework.py       # 게임 프레임워크

├── state_machine.py       # 상태 머신
├── title_mode.py          # 타이틀 화면 (마우스 지원)
├── tutorial_mode.py       # 조작법 화면
├── shop_mode.py           # 상점 화면 (마우스 지원)
├── option_mode.py         # 옵션 화면 (볼륨 조절)
├── play_mode.py           # 메인 게임 플레이
├── upgrade_mode.py        # 웨이브 간 업그레이드
├── gameover_mode.py       # 게임 오버 화면
├── player.py              # 플레이어 클래스 (차량 물리)
├── enemy.py               # 적 클래스 (일반/보스)
├── bullet.py              # 총알 클래스
├── explosion.py           # 폭발 이펙트
├── item.py                # 아이템 (HP 회복)
├── background.py          # 배경 클래스
├── minimap.py             # 미니맵 클래스
├── ui.py                  # UI 클래스
└── resource_path.py       # 리소스 경로 처리

리소스/
├── 01.캐릭터&몬스터&애니메이션/  # 차량, 적 스프라이트
├── 02.배경&프랍/                # 맵 타일
├── 03.아이템&아이콘/            # 아이템 아이콘
├── 04.GUI/                     # UI 이미지
├── 05.VFX/                     # 이펙트 애니메이션
├── SFX/                        # 효과음
└── 99.etc/                     # 로고 등
```

## 기술적 특징
